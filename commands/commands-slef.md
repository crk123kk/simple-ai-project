## 应该有什么

---

    review: 是对代码进行审查，检查代码质量、潜在问题、性能等方面。（找问题）

    clean: 对代码进行优化、简化、提高可读性、可维护性

    debug: 是根据错误信息或者问题进行分析，找出根本原因并提出修复方案。（根据问题找原因，并修复）

    feat: 是完成一个新的功能或者特性。


    ---- workflow ------ PRD -> Tasks -> Architecture -> Implement -----

    prd: 是编写产品需求文档，明确功能需求、用户需求、业务需求等方面。（明确需求）

    task: 是将需求拆解为具体的任务，明确每个任务的描述、输入输出、依赖关系、优先级和工时估算等方面。（拆解任务）

    architecture: 是设计系统的架构，包括模块划分、组件设计、数据流等方面。（设计系统架构）

    implement: 是根据设计的架构和任务进行具体的实现，编写代码、测试和部署等方面。（实现功能）

    ----- 其它 ------

    explain: 对代码块解读

    commit: 是将代码提交到版本控制系统中，记录代码的变更历史和版本信息等方面。（提交代码）

    changelog: 记录变更历史，生成周报
